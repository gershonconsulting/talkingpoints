# Talking Points — versions

Shown in the app sidebar, the Admin page and the home page footer. Bump on every release.

- **v1.13.0** (2026-11-19; merged with main 2026-11-20) — Same-day talking points with Cloudflare AI (Olivier: "We need to use Cloudflare AI for that using the format we created"). Every hourly run, each new Streak lead (created since the same-day start; Gershon's own pipelines: "Scheduled" only) without a talking point gets one built by Workers AI in the brief format (functions/_auto.js): Streak record (stage, contact, notes) + the lead company's website (from the contact's work email) + registry financials + the client's company, ICP and team. Saved as ready; a researched brief published later replaces it. Sending: every hourly run from 4 PM New York time (Fridays from 7 AM) emails the new leads not sent yet to the client's whole team — never twice (send_log, "same-day run"). Clients without an ICP get nothing. At most 8 AI talking points per hourly run. Safety defaults (review, 2026-11-20): no same-day sends on Saturday/Sunday New York time (NO_WEEKEND_SENDS) and no backlog — the first run only considers leads created in the last 24h (FIRST_RUN_LOOKBACK_HOURS, start stored once as SAME_DAY_STARTED_AT); Friday sends of researched briefs keep their 14-day rule. Builds on v1.12.5's buildAutoBrief (test mode kept) and v1.12.6 naming. Tests: test/auto_brief.test.mjs, test/same_day_window.test.mjs.
