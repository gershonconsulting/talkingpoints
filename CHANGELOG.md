# Talking Points — versions

Shown in the app sidebar, the Admin page and the home page footer. Bump on every release.

- **v1.9.5** (2026-11-09) — Fix: every Talking Points email subject starts with “[21] ” exactly once. sendEmail (Resend and social.gershon.ai relay paths) and GET /api/outbox/:id now enforce it (withReportPrefix in functions/_audience.js), so no caller can send “Talking Points : …” without it (seen 2026-11-06, DOWSERS); an existing “[21]” is never doubled. 1.9.4 and 1.10.0 are taken by open PRs #20 and #22.
- **v1.9.3** (2026-11-05) — Friday talking points: every Friday (first hourly run after 7 AM New York time) each client's 5 newest Streak leads get their researched talking point emailed to the client's recipients — never twice for the same lead (any earlier send counts), and never for a client whose ICP is not set. Gershon's own pipelines keep the “Scheduled” rule. Admin → “Friday talking points” shows, per client, the 5 newest leads: ✅ sent, 📨 goes out Friday, ❌ research needed. Owner-only POST /api/admin/briefs publishes a researched talking point from the browser (checks the lead is in that client's pipeline, never emails). Fix: the empty duplicate “#229 Altavia (Anne)” (slug altavia) no longer comes back — it was re-created from seed.sql on every cold start; Anne's real campaign is altavia-anne. Fix: app.js APP_VERSION matched to version.txt (a mismatch made open tabs reload in a loop).
- **v1.9.0** (2026-11-03) — Admin → Dashboard (owner only, live): every client in one table — Streak link ✅/❌ with a link to its pipeline, client logins, talking-point recipients, ICP ✅/❌, researched talking points, old drafts, talking points sent, date of the last one — plus totals.
- **v1.8.0** (2026-11-03) — Gershon's own pipelines are in Talking Points: “Gershon Consulting (Olivier)” = GC Pipeline, “Gershon Consulting (Julien)” = GC Campaigns (Julien signs in with his LinkedIn email). For these two, talking points are made ONLY for leads in the “Scheduled” stage (call booked): the Leads page lists only those, and the daily run asks for research on each scheduled lead without a brief. Client campaigns are unchanged (every new lead).
- **v1.7.0** (2026-10-30) — Admin → Add a client asks for everything at once: company name, client number, contact, professional email, LinkedIn login email, Streak pipeline, who receives the talking points, company description and ICP. Picking a company from client.gershon.ai fills number, pipeline and report emails; the ICP and company text come from its ICP.gershon.ai report (read-only KV links CRM_KV / ICP_KV).
- **v1.6.0** (2026-10-30) — No more quick AI drafts: only fully researched briefs are listed, opened, sent or emailed. “Create draft” is gone (leads show “Research in progress”); the daily run reports new leads as needing research instead of drafting them; the meeting run only sends a researched brief.
- **v1.5.5** (2026-10-30) — Fix: a lead can only be briefed for the client whose Streak pipeline it is in. “Create draft” refuses a lead from another campaign (it had filed 3 PhiTech leads — NxGen MDx, TrilliumBiO, Golden Valley — under Finance Montréal (Steve) after the campaign was switched in another tab); the meeting run no longer falls back to another client's Streak box.
